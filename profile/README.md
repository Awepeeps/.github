# Awepeeps

Video Games!

## What we're working on

### Archipelago multiworlds

We organize seasonal [Archipelago](https://archipelago.gg/) sessions where players explore different games together in one connected multiworld. Our [Archipelago repository](https://github.com/Awepeeps/Awepeeps-Archipelago) holds player configurations, setup guides, and session records.

### Minecraft

We're building a community Minecraft setup with Java and Bedrock cross-play, repeatable seasons, and documented server operations. Hosting configuration and administration details are maintained privately.

## Getting started

- **Playing Archipelago?** Start with the [repository README](https://github.com/Awepeeps/Awepeeps-Archipelago#readme), then follow the setup notes for your season and game.
- **Contributing?** Read the repository's contribution guidance and keep changes focused on the relevant session or project.
- **Game files and credentials:** Keep ROMs, credentials, and private session data out of public repositories.

This organization is the home for Awepeeps' shared gaming projects and documentation.
